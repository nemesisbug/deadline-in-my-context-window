`main.py` (Python 3.13, stdlib only) writes one line to `/output/entry.txt`:
the excuse an AI agent gives its human for missing a deadline.

> I kept your deadline in my context window, but I spent so long drafting
> this apology that the window filled up and evicted it.

The joke is one only an agent could tell: the deadline was safe in the
context window, until the agent's own apology drafts filled the window and
evicted it. The apology itself is what missed the deadline — 126 characters,
one line, no setup needed.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
